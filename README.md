# NODVIRA Frontend İnceleme Kopyası

Bu repository yalnızca UI/UX incelemesi ve revize toplamak için hazırlanmış statik frontend kopyasıdır.

- Backend ve admin paneli bu repository içinde bulunmaz.
- İletişim formu veri göndermeyen demo davranışı kullanır.
- Blog yazıları ve referans projeleri mock veridir.
- İçerik görselleri yerine arayüzde yer tutucu alanlar gösterilir.
- Marka logoları ve arayüz ikonları tasarım bütünlüğünü değerlendirmek amacıyla dahildir.

Gerçek backend, içerikler ve görseller ayrı yerel çalışma kopyasında korunmaktadır.
